# MrPratic

Paper 1.21.11 icin Turkce Practice sunucusu plugin projesi.

## Gereksinimler
- Paper 1.21.11
- Java 21

## Derleme
GitHub Actions, `main` dalina her push yapildiginda projeyi derler. Basarili derleme sonunda Actions > ilgili workflow > Artifacts bolumunden `MrPratic.jar` indirilebilir.

Yerel derleme:
```bash
gradle clean build
```

## Mevcut ilk surum
- Otomatik olusturulan ayri lobi dunyasi ve yesil/siyah spawn platformu
- Giriste lobiye isinlanma
- Turkce temel komutlar
- Rank prefix ayarlari ve varsayilan Çaylak ranki
- TAB baslik/altlik ve temel scoreboard
- GitHub Actions derleme workflow'u

FFA arenalari, gercek 1v1 eslestirme, kit editoru, bot yapay zekasi, Elo, party, ekonomi ve diger Practice sistemleri sonraki gelistirme asamalaridir; bu ilk surumde tamamlanmis degildir.
